backup-login

backup-login is a private application owned and operated by Jean Souza. It authorizes rclone, running on the owner's own server, to store encrypted restic backups of that server in the owner's own Google Drive. It is used only by its owner and is not offered to the public.

The app requests access to Google Drive only to create, read, update and delete those backup files. It does not use Google user data for any other purpose.
