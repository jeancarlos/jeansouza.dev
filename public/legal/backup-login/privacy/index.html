Privacy Policy

Last updated: 2026-10-07

backup-login is a private application owned and operated by Jean Souza (app homepage). It lets the open-source tool rclone, running on the owner's own server, back up that server to the owner's own Google Drive. It is used only by its owner and is not offered to the public.

Google user data accessed

With the owner's consent, the app requests the Google Drive scope (https://www.googleapis.com/auth/drive). It reads, creates, updates and deletes files in the backup folder of the owner's Drive. It also receives the OAuth access and refresh tokens needed for that. It does not access email, contacts, profile details beyond what the sign-in itself returns, or any other Google service.

How the data is used

The data is used only to store, list, restore and prune encrypted backup files of the owner's server. It is never used for advertising, never sold to data brokers or anyone else, never used for credit or lending decisions, and never used to train artificial intelligence or machine learning models.

Storage

The OAuth tokens are stored only in the rclone configuration file on the owner's server. The backup files are stored only in the owner's Google Drive.

Sharing, transfer and disclosure

Google user data is not shared with, transferred to or disclosed to any third party. The only parties involved are the owner and Google, which hosts the Drive files.

Data protection

Backups are encrypted with AES-256 by restic on the owner's server before upload, so Google Drive only ever holds encrypted data. All traffic to Google uses HTTPS (TLS). The token file is readable only by the owner's system account, and the server is reachable only over a private network.

Retention and deletion

Backup snapshots are kept under a rolling retention schedule and older ones are deleted automatically. The tokens are kept until access is revoked. Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the tokens immediately. Deleting the backup folder in Google Drive removes all stored backup data. A deletion request can also be sent to the contact address below and will be completed within 30 days.

Changes to this policy

If the way the app uses Google user data changes, this page will be updated and the date at the top will change before the new use begins.

Google API Services User Data Policy

backup-login's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
