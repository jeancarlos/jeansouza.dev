Privacy Policy

Last updated: 2026-10-07

backup-login is a private OAuth client used by a single person, Jean Souza, to let rclone back up his own server to his own Google Drive. It is not offered to the public.

Data accessed

With the owner's consent, the app accesses the owner's Google Drive to create, read, update and delete backup files. It does not access any other Google data.

Storage

The OAuth tokens and the backup data stay on the owner's own server and in the owner's Google Drive. Backups are encrypted by restic before upload.

Sharing

No data is sold, shared with third parties, or used for advertising, analytics or AI training.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
